# 英语发音测评网站与技术方案调研总结

**版本：V0.1**\
**日期：2026-09-27**\
**目标：筛选能够进行英语发音自动测评的网站及技术服务，并为后续 Android
多模态英语发音练习指导系统提供参考。**

------------------------------------------------------------------------

## 1. 调研目标

重点寻找具备以下能力的网站或服务：

-   浏览器或 App 直接使用麦克风录音
-   自动分析英语发音
-   支持美式英语
-   单词级发音评分
-   音素（Phoneme）级发音评分
-   流利度（Fluency）评价
-   完整度（Completeness）评价
-   重音、节奏和韵律（Prosody）评价
-   能够指出具体发音错误
-   最好提供 API，方便 Android/嵌入式系统后续接入

需要特别区分：

> **语音识别正确 ≠ 发音正确。**

普通 ASR
主要回答"用户说了什么"；真正的发音测评系统还需要判断"用户说得是否准确，以及哪里不准确"。

因此，**音素级测评能力是当前项目的重要评价指标。**

## 3. Microsoft Pronunciation Assessment

官方在线测试：

https://speech.microsoft.com/portal/pronunciationassessmenttool

核心能力包括 Pronunciation Accuracy、Word Accuracy、Phoneme
Accuracy、Fluency、Completeness 和 Prosody。

典型处理结构：

``` text
用户录音
   │
   ▼
Azure Speech
   │
   ├── Speech Recognition
   ├── Word Alignment
   ├── Phoneme Analysis
   ├── Accuracy
   ├── Fluency
   ├── Completeness
   └── Prosody
   │
   ▼
结构化评分结果
```

适合作为当前项目的 **Baseline / Benchmark**。

------------------------------------------------------------------------

## 4. ELSA Speech Analyzer

网站：

https://elsaspeak.com/en/speech-analyzer

主要分析能力包括：

-   Pronunciation
-   Intonation
-   Fluency
-   Grammar
-   Vocabulary

开发者 API：

https://elsaspeak.com/en/elsa-api/

可用于 Word Pronunciation、Sentence Pronunciation 和 Unscripted
Speech，并提供 Sentence / Word / Phoneme Score 与 Mispronunciation
Feedback 等信息。

ELSA 更适合作为最终产品体验和"测评 → 教学 → 纠错"闭环的参考。

------------------------------------------------------------------------

## 5. SpeechAce

网站：

https://www.speechace.com/

支持：

-   Pronunciation
-   Phoneme Accuracy
-   Word Accuracy
-   Fluency
-   Grammar
-   Vocabulary

并可映射 CEFR、IELTS、TOEFL、PTE、TOEIC 等体系。

值得重点研究其分层评分结构：

``` text
Audio
 ↓
Forced Alignment
 ↓
Phoneme Segmentation
 ↓
Phoneme Scoring
 ↓
Word Scoring
 ↓
Sentence Scoring
```

------------------------------------------------------------------------

## 6. Tono

网站：

https://tonospeak.com/

支持 English (United States)，并提供
Word、Phoneme、Fluency、Completeness、Prosody 等分析。

其底层使用 Microsoft Azure Speech Pronunciation
Assessment，因此特别适合与 Microsoft Speech Studio
对比，研究相同底层能力经过产品化后的 UI、错误反馈和训练流程。

------------------------------------------------------------------------

## 7. Flalingo Pronunciation Lab

网站：

https://start.flalingo.com/en/pronunciation-test

特点：

-   浏览器直接使用
-   不需要注册
-   可以自己输入单词
-   支持逐词分析
-   支持音素级分析
-   Sound 评分采用 0--100 等形式

适合快速测试 `fun / funk / hunt / hap / hop / ship / sheep / bad / bed`
等单词。

------------------------------------------------------------------------

## 8. Selora

网站：

https://getselora.com/

浏览器直接录音，可进行 syllable、sound 和发音错误定位分析。

可与 Microsoft、Tono 横向比较。

------------------------------------------------------------------------

## 9. BoldVoice

网站：

https://boldvoice.com/

定位为 **American Accent Training**，主要分析
Pronunciation、Stress、Clarity 和 Accent，同时结合真人 Accent Coach
教学内容。

特别值得参考其训练闭环：

``` text
检测错误
    ↓
解释错误
    ↓
展示正确口型
    ↓
用户模仿
    ↓
再次测评
```

## 11. 建议统一测试词库

第一组：

``` text
fun
funk
hunt
```

主要测试 `/ʌ/ /n/ /ŋ/ /k/`。

第二组：

``` text
hap
hop
```

用于测试元音差异。

第三组：

``` text
ship
sheep
```

重点测试 `/ɪ/` 与 `/iː/`。

第四组：

``` text
bad
bed
```

重点测试 `/æ/` 与 `/e/` 等元音差异。

## 12. 建议统一评价指标

  指标                 内容
  -------------------- ----------------------
  ASR                  是否正确识别单词
  Word Score           是否有单词评分
  Phoneme Score        是否有音素评分
  Error Location       能否指出具体错误音素
  Fluency              是否评价流利度
  Stress               是否评价重音
  Prosody              是否评价韵律
  Feedback             是否告诉用户如何改善
  IPA                  是否显示 IPA
  American English     是否明确支持 en-US
  API                  是否提供开发接口
  Latency              结果返回速度
  Cost                 API/订阅费用
  China Availability   中国大陆网络可用性

## 14. 推荐技术路线

### Phase 1：商业系统作为 Baseline

优先研究：

-   Microsoft Pronunciation Assessment
-   ELSA
-   SpeechAce

目标是确定成熟商业系统目前可以达到的发音评价能力。

### Phase 2：建立本地 Audio Pipeline

逐步研究：

``` text
VAD
 ↓
ASR
 ↓
Forced Alignment
 ↓
Phoneme
 ↓
GOP
 ↓
Pronunciation Score
```

潜在技术：

-   Whisper
-   wav2vec2
-   HuBERT
-   MFA
-   CTC Alignment
-   GOP
-   ONNX Runtime

Android 侧可考虑：

-   ONNX Runtime
-   MediaPipe
-   Rust

### Phase 3：加入视觉口型分析

``` text
Camera
 ↓
MediaPipe Face Landmarker
 ↓
Lip Landmarks
 ↓
Mouth Geometry
 ↓
Temporal Motion
```

进一步分析嘴唇张开程度、圆唇程度、嘴角宽度、上下唇位置、下颌运动以及发音过程中的动态变化，然后与
Audio 评分融合。

## 15. LLM 的合理职责

DeepSeek 等大语言模型不应直接承担底层音素评分。

更合理的分工：

``` text
Audio Model
    ↓
客观声音特征

Vision Model
    ↓
客观口型特征

Pronunciation Engine
    ↓
音素评分

        ↓

DeepSeek
    ↓
综合解释
    ↓
判断主要问题
    ↓
生成改善方法
    ↓
生成下一轮训练任务
```

核心原则：

> **小模型负责测量，大模型负责理解、解释和指导。**

这比单纯把录音发送给多模态大模型询问"发音准不准"更容易获得稳定、可重复、可量化的结果。

## 17. 当前结论

发音测评技术可以大致分成三层：

``` text
Level 1
Speech Recognition

“你说了什么？”
        ↓

Level 2
Pronunciation Assessment

“你说得准不准？”
        ↓

Level 3
Pronunciation Coaching

“哪里不准？”
“为什么不准？”
“嘴应该怎么动？”
“下一次应该怎么练？”
```

目前 Microsoft、SpeechAce 等已经较好覆盖 **Level 2**。

ELSA、BoldVoice 等进一步向 **Level 3** 发展。

当前规划的 **Android + Audio + Camera + MediaPipe/ONNX + DeepSeek**
系统真正值得形成差异化的部分也是 Level 3：

> 不仅给用户一个分数，而是结合声音和口型判断错误原因，并给出可以立即执行的纠正动作。

因此后续技术研发重点不应仅仅是"再做一个发音评分器"，而应该建立：

``` text
音素测评
   +
口型测评
   +
错误诊断
   +
个性化指导
   +
重复训练闭环
```

最终形成完整的：

**Multimodal Pronunciation Assessment & Coaching System**

即：

> **多模态英语发音测评与智能指导系统。**
