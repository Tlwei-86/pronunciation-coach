# Golden Audio Test Set (Spec Section 42)

This directory holds baseline WAV files for regression testing:
- `funk_good.wav`: Native-like /fʌŋk/ pronunciation.
- `funk_ah_like.wav`: Typical mistake where /ʌ/ shifts open toward /ɑ/.
- `funk_no_k.wav`: Missing final /k/ consonant release.
- `ship.wav` / `sheep.wav`: /ɪ/ vs /i/ minimal pair.
- `thin.wav` / `sin.wav`: /θ/ vs /s/ minimal pair.
